# 🚀 Developer Portfolio

A modern and responsive developer portfolio built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. It showcases my projects, technical skills, education, and contact information with smooth animations and a clean, component-based architecture.

## ✨ Features

- 🎨 Modern and responsive UI
- ⚡ Built with React + Vite
- 🎞️ Smooth animations using Framer Motion
- 🧩 Reusable component architecture
- 📱 Fully responsive across devices
- 🛣️ Multi-page navigation with React Router
- 💼 Interactive projects showcase
- 🛠️ Skills section with detailed technology information
- 📚 About page with education and learning journey
- 📬 Contact page with social links and contact form

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Framer Motion
- Lucide React
- React Icons

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### Navigate to the project

```bash
cd your-repository
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
